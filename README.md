# Flask Blog Tutorial

A tutorial blogging application built with Flask. It includes user accounts,
authentication, profile images, posts, password resets, error pages, and a
SQLite development database.

## Local setup

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Set the environment variables shown in `.env.example`.
4. Start the application with `python run.py`.

The SQLite database, local environment files, uploaded profile images, Python
caches, and IDE configuration are intentionally excluded from Git.
